Core Strategies

CaloMate의 4대 핵심 차별화 전략

경쟁사가 흉내 낼 수 없는 극강의 마찰 제거와 사용자 친화적 경험

🥗 CaloMate
🥘
01. 한식 복합식단 특화

밥, 국, 반찬 3~4가지가 한 컷에 담긴 한국식 상차림을 멀티모달 비전으로 분할 검출하고, 식약처 공공 DB와 연계해 정확도를 80% 이상으로 보장.

✓ 식약처 2,500종 외식 DB 매핑
🥣
02. 그램 미노출 사람 언어

화면에서 복잡한 그램(g) 숫자를 숨기고, 사용자가 일상에서 직관적으로 인지하는 "1그릇, 1접시, 1인분, 반 공기" 슬라이더로 즉시 보정.

✓ 저울 없는 100% 직관적 UX
⚡
03. 15초 이내 기록 완결

카메라 촬영 즉시 LLM 추정치 제시 → 1회 터치 보정 → 저장으로 이어지는 3단계 초압축 플로우를 구현해 기존 110초 대비 87% 시간 단축.

✓ 3초 내 비전 응답 목표
💪
04. 증량 1급 플로우 전용설계

체중 증량(벌킹)을 부가 기능이 아닌 1급 모드로 취급. 잉여 칼로리 섭취를 긍정적으로 축하하고, 근성장 맞춤 근력 운동을 추천.

✓ 국내 최초 증량 중심 대시보드
