## 1. 서비스 개요

### 1.1 한 줄 정의

CaloMate는 **사진 한 장으로 식사를 15초 안에 기록**하는 PWA 칼로리 트래커다. 그램(g) 환산 대신 "1그릇, 1접시, 1인분" 등 사람이 실제로 말하는 단위로 배식량을 보정하며, 증량·감량·유지 목표를 동등한 1급 기능으로 지원한다.

### 1.2 배경 및 문제 정의

| 구분 | 내용 | 근거 |
|------|------|------|
| 시장 기회 | 글로벌 식단·영양 앱 시장 CAGR 13.4%, AI 비전 로깅으로 패러다임 전환 중 | 마켓리서치 2-1 |
| 사용자 문제 | 국내 2030 직장인의 82%가 식단 기록을 3주 이내 포기, 1위 원인은 "그램 단위 입력/무게 측정의 번거로움"(64.8%) | 마켓리서치 2-6 |
| 경쟁 공백 | MyFitnessPal(Meal Scan)·Welling 등은 사진 인식을 이미 제공하나, 한식/복합 가정식 인식 정확도와 국내 벌킹(증량) 수요 대응이 미흡 | 마켓리서치 2-2, 2-3, 2-7, 착수보고서 시장환경 업데이트 |

### 1.3 핵심 가치제안 (Value Proposition)

| # | 가치제안 | 설명 |
|---|----------|------|
| 1 | 15초 기록 완결 | 촬영 → 자동 인식 → 1회 보정 → 저장까지 15초 이내 (경쟁 앱 평균 110초 대비 대폭 단축) |
| 2 | 그램을 숨기는 사람 언어 UX | "1그릇/반그릇/1접시" 슬라이더로 끝까지 직관성 유지, 내부적으로만 표준 중량(식약처 DB)과 매핑 |
| 3 | 한식/가정식 인식 최적화 | 국/찌개/반찬 등 복합 식단 다중 객체 인식에 특화 |
| 4 | 증량=감량 동등 지원 | 벌킹 목표 사용자에게 칼로리 잉여를 긍정적으로 표시하고 근력 운동 추천 |

> 출처: PRD.md "차별점" 섹션, 마켓리서치 4.3 차별화 기회

## 2. 대상 사용자 및 페르소나

### 2.1 주 타깃

22~35세 직장인 중 체중을 지속 가능하게 변화(증량/감량)시키고 싶으나, 기존 앱의 기록 부담으로 중도 포기한 경험이 있는 사용자 (PRD.md 대상 사용자 참고).

### 2.2 페르소나 (마켓리서치 3.5 기반)

| 페르소나 | 목표 | 핵심 니즈 | 페인 포인트 |
|----------|------|-----------|--------------|
| 감량 직장인 (P1) | 체지방 감량 | 외식/구내식당 식사를 눈치 보지 않고 10~15초 안에 기록 | 재료별 그램 검색·환산 피로로 2주 내 이탈 |
| 증량(벌킹) 직장인 (P2) | 근육량 증가, 건강한 체중 증량 | 매일 잉여 칼로리·단백질 목표 달성 여부 확인 | 초과 섭취 시 경고(빨간색) 위주 UI로 인한 심리적 불편 |
| 유지/헬시플레저 직장인 (P3) | 식사 밸런스 유지 | 오늘 더 먹은 만큼 어떤 운동으로 상쇄할지 즉시 파악 | 칼로리 숫자만 보여주고 행동 제안이 없음 |

> MVP는 P1·P2를 우선 타깃으로 하며, P3는 4번 기능(맞춤 운동 추천)으로 부분 충족한다.

## 3. MVP 범위 정의

### 3.1 범위 원칙

착수보고서 3.1 "범위 내(In Scope)" 6개 항목을 그대로 MVP 기능 단위로 전환한다. **In Scope에 없는 기능은 MVP에 포함하지 않는다.**

### 3.2 In Scope → MVP 기능 매핑

| # | 착수보고서 In Scope 항목 | MVP 기능명 | 우선순위 (MoSCoW) |
|---|--------------------------|------------|---------------------|
| 1 | 사진 기반 식사 인식 (카메라 촬영 → LLM 비전 API 연동 → 음식/칼로리/영양성분 추정) | F-1 사진 촬영 식사 인식 | Must |
| 2 | 사람 언어 기반 배식량 보정 UI (1그릇/1접시/1인분 등) | F-2 배식량 보정 슬라이더 | Must |
| 3 | 체중 목표 설정 및 추적 (증량/감량/유지, 칼로리 밸런스·체중 추이 시각화) | F-3 체중 목표 및 칼로리 밸런스 | Must |
| 4 | 맞춤 운동 추천 (섭취/소모 칼로리와 목표 기반) | F-4 맞춤 운동 추천 | Should |
| 5 | 기록 히스토리 및 일/주 단위 대시보드 | F-5 기록 히스토리 및 대시보드 | Must |
| 6 | PWA 형태 배포 (모바일 우선 반응형) | F-6 PWA 배포 | Must |

> MoSCoW 우선순위는 착수보고서 2. 프로젝트 목표의 "단기: 핵심 기능 1~2 MVP 출시" 문구에 맞춰 F-1·F-2·F-6(기록 파이프라인)을 최우선(Must)으로 하고, F-4(운동 추천)는 목표 대비 밸런스 계산(F-3) 이후 확장 가능한 Should로 배치한다.

### 3.3 MVP 명시적 제외 항목 (Out of Scope 재확인)

착수보고서 3.2 범위 외 항목은 MVP뿐 아니라 본 서비스기획서 전 범위에서 제외한다.

| 제외 항목 | 사유 |
|-----------|------|
| 네이티브 iOS/Android 앱 | PWA로 대체 (마켓리서치 2-9, 3.4 근거: PWA 초기 전환율 +45%, 설치 장벽 제거) |
| 웨어러블 기기 연동 (Apple Health, Google Fit 등) | 향후 확장 검토 항목, MVP 비대상 |
| 소셜 기능 (친구 추가, 랭킹, 커뮤니티) | 핵심 가치(빠른 기록)와 무관, MVP 비대상 |
| 영양사/트레이너 매칭·상담 기능 | 전문가 리소스 필요, MVP 비대상 |
| 결제/구독 과금 모델 | 가격 정책 미정 (PRD.md 비고 참고) |

## 4. 핵심 기능 상세 (MVP)

### F-1. 사진 촬영 식사 인식

- **설명**: 카메라 촬영 또는 갤러리 업로드 → LLM 비전 API가 음식 종류·구성 요소를 다중 객체로 검출 → 칼로리/매크로(탄단지) 추정
- **성능 목표**: 사진 업로드 후 결과 반환 3초 이내, 상위 1개 후보 정답률 80% 이상 (PRD 비기능 요건)
- **예외 처리**: 인식 실패/오인식 시 후보군 재선택 또는 F-2 슬라이더로 즉시 수동 보정. 식품 알레르기 미감지 경고 및 의료 면책 문구 상시 노출 (마켓리서치 4.2 위험 대응)

### F-2. 배식량 보정 슬라이더 (사람 언어 UX)

- **설명**: 그램(g) 대신 "반 공기/1공기/1접시/1인분" 등 직관적 단위로 배식량 보정. 내부적으로 식약처 외식 영양성분 DB의 표준 중량(예: 1공기=210g)과 양방향 매핑
- **UX 원칙**: 화면 어디에도 그램 단위를 기본 노출하지 않음 (마켓리서치 2-7 근거: 그램 인지도 16% vs 그릇/인분 인지도 94%)

### F-3. 체중 목표 및 칼로리 밸런스

- **설명**: 증량/감량/유지 목표 설정 → 목표 대비 일일 칼로리 밸런스(섭취-소모)와 체중 추이 시각화
- **원칙**: 증량 목표 사용자에게 칼로리 초과를 경고색(빨강)이 아닌 긍정적 잉여로 표시 (마켓리서치 2-3, 2-6 근거: 증량 니즈 2030 남성 42%, 기존 앱은 감량 편향 UI)

### F-4. 맞춤 운동 추천

- **설명**: F-3의 당일 칼로리 밸런스와 목표(증량/감량/유지)에 따라 운동 유형·강도·시간 제안
- **MVP 범위**: 정적 규칙 기반 추천(예: 초과 300kcal → 유산소 30분 제안)으로 시작하며, MacroFactor식 적응형 TDEE 알고리즘 등 고도화는 4번 항목 확장으로 향후 검토 (착수보고서 In Scope "맞춤 운동 추천" 범위 내 최소 구현)

### F-5. 기록 히스토리 및 대시보드

- **설명**: 일/주 단위 섭취·소모 칼로리, 매크로 영양소, 체중 변화 요약 조회

### F-6. PWA 배포

- **설명**: Next.js + Tailwind CSS 기반 PWA. 홈 화면 추가, 서비스 워커 오프라인 캐싱(최근 기록 열람)
- **기술 근거**: PRD.md 기술 스택, 마켓리서치 2-9 (PWA 전환율 우위, 스토어 수수료 회피)

## 5. 사용자 시나리오

### 5.1 감량 직장인 (P1) — 점심 식사 기록

1. 구내식당에서 김치찌개+밥+반찬 3종을 스마트폰으로 촬영
2. F-1이 3초 내 "김치찌개, 밥, 계란말이, 나물" 등 구성 요소와 예상 칼로리 표시
3. F-2 슬라이더로 "밥 = 반 공기"만 한 번 보정
4. 저장 → 총 소요 시간 15초 이내 완료

### 5.2 증량(벌킹) 직장인 (P2) — 저녁 식사 및 밸런스 확인

1. 저녁 식사 기록 후 F-3 대시보드에서 "목표 대비 +350kcal 잉여 (증량 목표 달성 중)" 긍정적 표시 확인
2. F-4에서 "오늘 단백질 섭취량 충분, 하체 근력 운동 20분 추천" 제안 수신

## 7. 향후 확장 로드맵 (MVP 이후, 본 문서 범위 외)
