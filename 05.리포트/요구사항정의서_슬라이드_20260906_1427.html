Core Pipeline

15초 식사 기록 완결 파이프라인 (REQ-001 ~ REQ-005)

수기 검색과 무게 측정 단계를 완전히 제거한 3단계 초압축 인터랙션

🥗 CaloMate
REQ-001 (1초)
카메라 촬영 / 업로드

웹 카메라 뷰파인더 즉시 구동. 촬영 즉시 클라이언트 이미지 자동 리사이징 및 압축 후 1초 내 업로드.

✓ 모바일 PWA 네이티브 감각 셔터
➔
REQ-002 (3초)
LLM 비전 자동 인식

다중 객체 검출(Multi-object)로 밥, 국, 반찬 분할 식별. 칼로리 및 탄단지 매크로 자동 추정 (정답률 80%+).

✓ 비전 응답 지연 3초 이내 보장
➔
REQ-003~005 (10초)
사람 언어 보정 & 저장

"밥 반 공기", "찌개 1그릇" 슬라이더 원터치 조절 후 즉시 [기록 완료] 탭. 총 15초 내 DB 영구 저장.

✓ 저울 없는 1회 터치 보정 완료
📋 핵심 인수 기준 (Acceptance Criteria): REQ-005
• 성능 기준: 정상 네트워크 환경에서 셔터 클릭부터 저장 완료 팝업까지 15.0초 초과 시 테스트 실패
• 다중 객체 검출: 한식 상차림(밥+국+반찬)에서 주 메뉴 2종 이상 자동 분할 카드 표시 필수
• 조작 단순성: 텍스트 입력창 없이 슬라이더/버튼 터치만으로 100% 입력 완료 가능

UX Principle

사람 언어 배식량 UI & 그램(g) 미노출 원칙 (REQ-003, REQ-004)

사용자 인지 모델과 백엔드 정밀 데이터베이스 간의 완벽한 양방향 매핑

🥗 CaloMate
📱 프론트엔드 UI (사람 언어) REQ-004 그램 비노출
🍚 흑미밥 한 공기
🥘 차돌된장찌개 1 뚝배기 (1그릇)
🚫 원칙: 사용자가 숫자로 210g, 350g을 계산할 필요가 없도록 그램 표시를 화면에서 철저히 은닉.
⚙️ 백엔드 표준 영양 DB 연계
식약처 외식 영양성분 DB 매핑

1공기 = 210g (약 310 kcal, 탄 68g, 단 6g, 지 1g)
1뚝배기 = 400g (약 220 kcal, 탄 12g, 단 14g, 지 12g)

비례 계산 엔진 (Ratio Calculator)

슬라이더 값(0.5x, 1.0x, 1.5x) 변경 시 내부 정밀 칼로리/매크로 즉시 연동 계산 및 PostgreSQL 저장.

인수 기준 검증 요건

UI 상에는 '1공기'로 표시되더라도 DB 컬럼에는 정밀 그램수 및 환산 매크로 수치가 정확히 저장되어야 함.

Goal Management

증량(벌킹) 1급 전용 대시보드 & 목표 밸런스 (REQ-007 ~ REQ-009)

기존 감량 편향 앱의 적색 경고 관성을 탈피하고 증량을 1급 기능으로 설계

🥗 CaloMate
💪 증량(벌킹) 전용 모드 (REQ-008) MUST
오늘의 칼로리 잉여 (Surplus)
+380 kcal 잉여 달성! 🎉

"목표치 대비 훌륭하게 잉여 칼로리를 섭취 중입니다. 근성장에 최적화되었습니다."

• 컬러 규칙: 초과 섭취 시 절대 빨간색(경고) 사용 금지 $\rightarrow$ 에메랄드/블루 계열 적용
• 단백질 트래킹: 체중당 1.6g~2.0g 목표 달성도 프로그레스 바 최상단 배치
• 동기부여: "벌킹 성공!", "근육 합성 골든타임" 등 긍정 축하 메시지 트리거
⚖️ 감량 및 유지 밸런스 게이지 (REQ-009) MUST
오늘의 칼로리 밸런스 잔여량
잔여 540 kcal

"저녁 식사로 가벼운 단백질 위주 식단을 권장합니다."

• 원형 게이지: 기초대사량(BMR) + 활동 소모량 대비 실시간 섭취량 시각화
• 잔여 칼로리 연동: 초과 시 즉시 REQ-010 맞춤 유산소 운동(분 단위) 자동 매핑
• 감량 페이스: 주간 -0.5kg 안전 감량 가이드라인에 따른 일일 칼로리 디피싯 유지

User Stories

핵심 사용자 스토리 (US-001 ~ US-006)

사용자가 체감하는 실질적 가치와 엔지니어링 요구사항의 연계

🥗 CaloMate
US-001 & US-002
점심 식사 15초 기록 (P1)

As a 바쁜 다이어트 직장인은,
I want 사진을 찍으면 3초 안에 음식명과 칼로리를 채워주길 원한다.
So that 동료 눈치 없이 15초 안에 기록을 마치기 위해.
연결: REQ-001, 002, 005

US-003
벌킹 잉여 칼로리 축하 (P2)

As a 증량 중인 웨이트 직장인은,
I want 칼로리 초과를 경고가 아닌 긍정적 잉여(Surplus)로 보길 원한다.
So that 죄책감 없이 근육을 늘리고 단백질 섭취를 동기부여 받기 위해.
연결: REQ-007, 008

US-005 & US-006
운동 추천 & PWA 실행

As a 모바일 웹 사용자는,
I want 앱 설치 없이 홈 화면 추가로 켜고, 먹은 만큼 맞춤 운동을 추천받길 원한다.
So that 번거로운 절차 없이 생활 속에서 칼로리를 통제하기 위해.
연결: REQ-010, 013, 014
