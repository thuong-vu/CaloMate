## 참고: 화면 설계 작성 팁

1. **플랫폼**: CaloMate는 모바일 우선 PWA이므로 375px 기준으로 통일 설계(PC 대응은 반응형 확대 레이아웃으로 후속 검토)
2. **ASCII 와이어프레임**: 코드 블록(```)으로 감싸서 레이아웃 표현
3. **컴포넌트 테이블**: 각 UI 요소의 타입, 설명, 인터랙션을 명확히 기술
4. **상태 정의**: 기본/로딩/에러/빈 상태(및 CaloMate 특화 상태인 오프라인·저신뢰도)를 반드시 고려
5. **그램 미노출 원칙(REQ-004)**: 배식량 관련 모든 화면에서 최우선으로 검증
6. **네이밍 규칙**: 화면 ID는 정보구조도(#8)의 URL 체계와 1:1 매핑되는 `MOB-` 접두사 사용
