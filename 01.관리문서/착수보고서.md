## 1. 프로젝트 개요

CaloMate는 사진 한 장으로 식사를 기록하는 PWA(Progressive Web App) 칼로리 트래커다. 사용자가 음식을 촬영하면 LLM 비전 API가 음식 종류와 구성을 자동 인식하고, 배식량은 그램(g) 환산이 아니라 "1그릇, 1접시, 1인분"처럼 사람이 실제로 말하는 단위로 보정한다. 체중 목표는 증량/감량/유지를 동등한 우선순위로 지원하며, 목표에 맞춘 운동을 추천한다.

핵심 UX 목표는 **한 끼 기록을 15초 이내에 완료**하는 것이다. 이는 MyFitnessPal, Lifesum, Yazio 등 기존 앱이 요구하는 재료 단위 수기 입력과 그램 환산의 번거로움 때문에 기록을 중도 포기한 사용자층(22~35세 직장인)의 이탈을 줄이기 위함이다.

**시장 환경 업데이트** (2026-08-30 리서치, [경쟁사분석_사진인식및증량기능.md](../00.통합자료실/참고자료/경쟁사분석_사진인식및증량기능.md) 참고): MyFitnessPal이 2026년 3월 Cal AI를 인수해 Premium+ 등급에 사진 인식 기능(Meal Scan)을 이미 탑재했고, Welling이 "사진 로깅 + 증량 1급 지원"을 동시에 내세우는 직접 경쟁자로 부상했다. 따라서 CaloMate의 차별점은 사진 인식 유무가 아니라 한식/가정식 인식 정확도, 그램 미노출 UX, 15초 기록이라는 구체적 성능 목표, 증량 전용 설계에 있다.

## 3. 프로젝트 범위

### 3.1 범위 내 (In Scope)

- 사진 기반 식사 인식 (카메라 촬영 → LLM 비전 API 연동 → 음식/칼로리/영양성분 추정)
- 사람 언어 기반 배식량 보정 UI (1그릇/1접시/1인분 등)
- 체중 목표 설정 및 추적 (증량/감량/유지, 목표 대비 칼로리 밸런스·체중 추이 시각화)
- 맞춤 운동 추천 (섭취/소모 칼로리와 목표 기반)
- 기록 히스토리 및 일/주 단위 대시보드
- PWA 형태 배포 (모바일 우선 반응형)

### 3.2 범위 외 (Out of Scope)

- 네이티브 iOS/Android 앱 (PWA로 대체)
- 웨어러블 기기 연동 (Apple Health, Google Fit 등) — 향후 확장 검토
- 소셜 기능 (친구 추가, 랭킹, 커뮤니티)
- 영양사/트레이너 등 전문가 매칭·상담 기능
- 결제/구독 과금 모델 (가격 정책 미정, PRD 비고 참고)
